# Vai dar salto? — previsão de abertura do CNP Boituva

Página pública gerada automaticamente por um projeto acadêmico (TCC): previsão
de 15 dias da chance de a área de salto do Centro Nacional de Paraquedismo
(Boituva, SDOI) estar liberada para cada categoria (AI/A, B, C, D).

**Não é uma fonte oficial.** Quem decide se a área abre é sempre o RTA no
local, no dia.

- O tempo combina ECMWF (IFS e AIFS), GFS e o ensemble do ECMWF, corrigidos
  estatisticamente para Boituva com previsões antigas de 8 centros
  meteorológicos.
- A decisão por categoria vem de um modelo treinado com decisões reais de RTA.
- A página é atualizada sozinha quando sai uma rodada nova dos modelos
  (≈ 05h, 10h e 16h, horário de Brasília).

Dados meteorológicos: Open-Meteo (CC BY 4.0) e ECMWF open data (CC BY 4.0).
